개인정보처리방침

생각정리 도구함 · 시행일 2026년 9월 12일

"생각정리 도구함"(이하 "본 서비스")은 이용자의 개인정보를 소중히 여기며, 관련 법령과 Google API 서비스 사용자 데이터 정책을 준수합니다. 본 서비스는 별도의 서버나 데이터베이스를 운영하지 않는 정적 웹앱으로, 이용자의 데이터를 운영자가 수집·보관하지 않는 것을 원칙으로 합니다.

1. 처리하는 정보

  • Google 계정 기본 정보(이름, 이메일, 프로필 사진) — Google 로그인 시 화면 우측 상단에 로그인 상태를 표시하기 위해서만 사용합니다. 이 정보는 이용자의 브라우저 안에서만 처리되며, 운영자에게 전송되거나 별도로 저장되지 않습니다.
  • 이용자가 앱에 입력한 내용(계획표, 메모, 일기 등) — 이용자 본인의 Google Drive에 "생각정리 도구함 데이터.json" 파일 하나로 저장됩니다. 로그인하지 않은 경우에는 이용 중인 브라우저의 저장 공간(localStorage)에만 저장됩니다.

2. Google Drive 접근 범위

본 서비스는 Google Drive 권한 중 가장 좁은 범위인 drive.file만 사용합니다. 이 권한으로는 본 서비스가 직접 생성한 파일만 읽고 쓸 수 있으며, 이용자의 다른 드라이브 파일·사진·문서에는 어떠한 접근도 할 수 없습니다.

3. 데이터의 보관과 제3자 제공

  • 이용자의 데이터는 이용자 본인의 Google 계정(드라이브)에만 보관됩니다. 운영자는 이용자의 데이터에 접근할 수 없고, 이를 수집·열람·판매·제공하지 않습니다.
  • 본 서비스는 이용자 데이터를 광고 등 어떤 목적으로도 제3자에게 제공하지 않습니다.

4. 이용자의 권리와 삭제 방법

  • 이용자는 언제든 자신의 드라이브에서 "생각정리 도구함 데이터.json" 파일을 삭제하여 모든 앱 데이터를 지울 수 있습니다.
  • Google 계정 → 보안 → 서드파티 앱 액세스에서 본 서비스의 연결을 언제든 해제할 수 있습니다.
  • 브라우저 저장 데이터는 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다.

5. 쿠키 및 유사 기술

본 서비스는 광고·추적 쿠키를 사용하지 않습니다. 로그인 유지 표시와 데이터 임시 저장을 위해 브라우저의 localStorage만 사용합니다.

6. Google API 서비스 사용자 데이터 정책 준수

본 서비스의 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy (제한적 사용 요건 포함)를 준수합니다.

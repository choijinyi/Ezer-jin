# 생각정리 도구함

성공적인 인생을 계획하고 실천하기위해서 필요한 생각정리 도구 10종을 웹에서 바로 쓰는 웹앱이다.
생각 나무 계획표(만다라트)·로직트리·마인드맵·퀘스천맵·브레인스토밍·브레인라이팅·독서정리 노트·일기(데일리 리포트)·인생그래프·버킷리스트, 그리고 "오늘 해야 할 일" 대시보드로 구성된다.

- 정적 파일 3개(`index.html`, `config.js`, `README.md`)만으로 동작한다. 서버·DB·운영 비용이 없다.
- **누구나 자신의 구글 계정으로 로그인**하면 데이터가 **본인 구글 드라이브의 "생각정리 도구함 데이터.json" 파일 하나**에 자동 저장된다. 이 앱은 `drive.file` 권한만 사용하므로 **자신이 만든 그 파일 외에는 사용자의 어떤 드라이브 파일에도 접근할 수 없고**, 운영자도 사용자 데이터를 볼 수 없다.
- `drive.file`은 구글이 비민감 권한으로 분류하므로 **별도의 앱 인증 심사나 인원 제한 없이 전체 공개(프로덕션)가 가능하다.**
- 로그인하지 않으면 해당 브라우저(localStorage)에만 저장된다.

## 배포 절차 (운영자용, 최초 1회)

### 1. Google Cloud에서 OAuth 클라이언트 만들기

1. [Google Cloud Console](https://console.cloud.google.com/)에서 새 프로젝트를 만든다. (결제 계정·카드 등록 불필요, 전 과정 무료)
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API**를 찾아 "사용"을 누른다.
3. **API 및 서비스 → OAuth 동의 화면**에서
   - 사용자 유형: **외부(External)**
   - 앱 이름·지원 이메일을 입력하고 저장한다.
   - 범위(Scopes)에 `.../auth/drive.file`, `openid`, `email`, `profile`을 추가한다. (민감/제한 범위는 추가하지 않는다)
   - 설정을 마친 뒤 **"앱 게시(프로덕션으로 전환)"** 를 누른다. 비민감 범위만 쓰므로 심사 없이 게시되며, 테스트 사용자 등록도 필요 없다.
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**에 배포 주소의 원본(origin)을 추가한다.
     - 운영 도메인: `https://thinktool.kr`
     - GitHub Pages(구 주소): `https://choijinyi.github.io`
     - 로컬 테스트용(선택): `http://localhost:8000`
   - 만들어진 **클라이언트 ID**(`....apps.googleusercontent.com`)를 복사한다.

### 2. `config.js`에 클라이언트 ID 넣기

```js
window.TT_CONFIG = {
  clientId: "여기에-복사한-클라이언트-ID.apps.googleusercontent.com"
};
```

### 3. GitHub Pages로 공개하기

1. 이 저장소의 **Settings → Pages**로 간다.
2. Source를 **Deploy from a branch**로 두고, 배포할 브랜치와 `/ (root)`를 선택해 저장한다.
3. 몇 분 뒤 `https://thinktool.kr/` 주소가 열린다. 이 링크를 공유하면 누구나 사용할 수 있다.

> 주소가 위와 다르면(사용자명·저장소명이 다르면) 1번의 "승인된 자바스크립트 원본"도 그 주소의 원본으로 맞춰야 한다.

## 사용자 안내

1. 배포 주소에 접속한다.
2. 오른쪽 위 **[Google 계정으로 로그인]**을 누른다.
3. 이후 입력하는 모든 내용은 본인 구글 드라이브의 "생각정리 도구함 데이터.json" 파일에 자동 저장된다. 어느 기기에서든 같은 계정으로 로그인하면 이어서 쓸 수 있다.
4. 로그인하지 않으면 그 기기 브라우저에만 저장된다.

## 데이터와 권한

- **권한 범위**: `drive.file` — 이 앱이 직접 만든 파일만 읽고 쓸 수 있다. 사용자의 다른 드라이브 파일·사진·메일에는 접근이 불가능하다.
- **저장 파일**: 드라이브의 "생각정리 도구함 데이터.json" 1개. 로그인 시 원격 파일을 불러오고, 입력할 때마다 1.5초 간격으로 업로드한다(원격 우선). 파일을 지우면 앱 기록도 사라지므로 지우지 않도록 안내한다.
- **연결 해제**: 사용자는 [구글 계정 → 보안 → 서드파티 앱 액세스](https://myaccount.google.com/connections)에서 언제든 이 앱의 연결을 끊을 수 있다.
- **비용**: OAuth 로그인과 Drive API는 무료 할당량으로 운영되며 이 앱의 사용 패턴(사용자당 작은 JSON 파일 1개)으로는 과금이 발생하지 않는다. 저장 용량은 각 사용자 본인의 드라이브 용량을 사용한다.

## 로컬에서 미리 보기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`config.js`의 clientId가 비어 있으면 로그인 버튼 대신 "클라우드 저장 미설정" 안내가 표시되고, localStorage 저장만 동작한다.

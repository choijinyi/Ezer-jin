# 생각정리 도구함

복주환 《생각정리스킬》의 생각정리 도구 10종을 웹에서 바로 쓰는 학습용 웹앱이다.
생각 나무 계획표(만다라트)·로직트리·마인드맵·퀘스천맵·브레인스토밍·브레인라이팅·독서정리 노트·일기(데일리 리포트)·인생그래프·버킷리스트, 그리고 "오늘 해야 할 일" 대시보드로 구성된다.

- 정적 파일 3개(`index.html`, `config.js`, `README.md`)만으로 동작한다. 서버·DB가 필요 없다.
- 학생마다 **자신의 구글 계정으로 로그인**하면 데이터가 **본인 구글 드라이브의 앱 데이터 영역**(`thinktools.json`)에 자동 저장된다. 교사나 다른 학생은 서로의 데이터를 볼 수 없다.
- 로그인하지 않으면 해당 브라우저(localStorage)에만 저장된다.

## 배포 절차 (교사용, 최초 1회)

### 1. Google Cloud에서 OAuth 클라이언트 만들기

1. [Google Cloud Console](https://console.cloud.google.com/)에서 새 프로젝트를 만든다.
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API**를 검색해 "사용"을 누른다.
3. **API 및 서비스 → OAuth 동의 화면**에서
   - 사용자 유형: **외부(External)**
   - 앱 이름·지원 이메일을 입력하고 저장한다.
   - 범위(Scopes)에 `.../auth/drive.appdata`, `openid`, `email`, `profile`을 추가한다.
   - **게시 상태가 "테스트"인 동안에는 "테스트 사용자"에 등록된 구글 계정(최대 100명)만 로그인할 수 있다.**
     한 학급 규모라면 학생들의 구글 이메일을 테스트 사용자로 등록하는 방법이 가장 간단하다.
     100명이 넘거나 등록이 번거로우면 "앱 게시"를 하되, 인증 심사 전까지는 로그인 시 경고 화면이 나올 수 있다.
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**에 배포 주소의 원본(origin)을 추가한다.
     - GitHub Pages를 쓰면: `https://choijinyi.github.io`
     - 로컬 테스트도 하려면: `http://localhost:8000`
   - 만들어진 **클라이언트 ID**(`....apps.googleusercontent.com`)를 복사한다.

### 2. `config.js`에 클라이언트 ID 넣기

```js
window.TT_CONFIG = {
  clientId: "여기에-복사한-클라이언트-ID.apps.googleusercontent.com"
};
```

### 3. GitHub Pages로 공개하기

1. 이 저장소의 **Settings → Pages**로 간다.
2. Source를 **Deploy from a branch**로 두고, 배포할 브랜치와 `/ (root)`를 선택해 저장한다.
3. 몇 분 뒤 `https://choijinyi.github.io/ezer-jin/` 주소가 열린다. 이 주소를 학생들에게 배포한다.

> 주소가 위와 다르면(사용자명·저장소명이 다르면) 1번의 "승인된 자바스크립트 원본"도 그 주소의 원본으로 맞춰야 한다.

## 학생 사용법

1. 배포 주소에 접속한다.
2. 오른쪽 위 **[Google 계정으로 로그인]**을 누르고 학교/개인 구글 계정으로 로그인한다.
3. 이후 입력하는 모든 내용은 자동으로 본인 구글 계정에 저장된다. 집·학교 어느 기기에서든 같은 계정으로 로그인하면 이어서 쓸 수 있다.
4. 로그아웃하거나 로그인하지 않으면 그 기기 브라우저에만 저장된다.

## 데이터 저장 방식

- 저장 위치: 각 사용자의 구글 드라이브 **앱 데이터 영역**(appDataFolder). 드라이브 목록에는 보이지 않는 앱 전용 공간으로, 이 앱만 읽고 쓸 수 있다.
- 파일: `thinktools.json` 1개. 로그인 시 원격 파일을 불러오고, 입력할 때마다 1.5초 간격으로 업로드한다(원격 우선).
- 삭제: 사용자가 구글 계정 설정 → 보안 → 서드파티 앱 액세스에서 이 앱의 연결을 해제하고 데이터를 삭제할 수 있다.

## 로컬에서 미리 보기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`config.js`의 clientId가 비어 있으면 로그인 버튼 대신 "클라우드 저장 미설정" 안내가 표시되고, localStorage 저장만 동작한다.
